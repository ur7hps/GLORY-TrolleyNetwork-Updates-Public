# GLORY Trolley Network Studio

**Программа для автоматического создания контактной сети на картах OMSI / openOMSI.**

GLORY Trolley Network Studio анализирует файлы выбранной карты, находит сплайны контактной сети и формирует файл `trolley.txt`. Программа помогает подготовить контактную сеть и её элементы без ручного построения каждого участка в текстовом файле.

## Что умеет программа

- **Анализ карты OMSI / openOMSI.** Проверяет выбранную папку карты с файлом `global.cfg` и сканирует файлы участков карты `tile_*.map`.
- **Поиск контактных сплайнов.** Анализирует используемые картой сплайны и помогает автоматически определить профиль контактной сети `.SLI`.
- **Автонастройка расстояния между проводами.** Если профиль содержит необходимые данные, программа определяет расстояние между парой контактных проводов. При необходимости профиль и параметры можно задать вручную.
- **Построение контактной сети.** Формирует участки сети в `trolley.txt`, объединяет связанные отрезки и автоматически обнаруживает трёхсторонние стрелки.
- **Настройка электрических параметров.** Доступны напряжение сети 550, 600, 750 или 800 В, расстояние между проводами, шероховатость, сопротивление фидера, рекуперация и состояние секции.
- **Проверка результата.** Выполняет внутренние проверки сформированного файла и создаёт диагностический отчёт `trolley_generation_report.txt` с информацией о найденных элементах, стрелках, связях и возможных геометрических разрывах.
- **Резервная копия.** Перед заменой уже существующего `trolley.txt` программа сохраняет его копию.

## Как пользоваться

1. Скачайте ZIP-архив и распакуйте его в папку, доступную для записи.
2. Запустите `GLORY.TrolleyNetwork.Studio.exe`.
3. Нажмите **«Выбрать папку карты»** и укажите корневую папку карты OMSI / openOMSI, в которой находится `global.cfg`.
4. Оставьте рекомендуемую автонастройку или задайте профиль `.SLI` и параметры вручную.
5. Нажмите **«СГЕНЕРИРОВАТЬ trolley.txt»**.
6. Изучите итоговую сводку и файл диагностического отчёта. Перед использованием результата рекомендуется проверить его на копии карты.

Файл `trolley.txt` и диагностический отчёт сохраняются в папке выбранной карты.

## Автоматические обновления

При запуске GLORY проверяет наличие новой версии. Если в этом репозитории опубликован более свежий релиз, программа предложит скачать и установить обновление. Загруженный архив проверяется по размеру и SHA-256 перед установкой.

Новые сборки публикуются автоматически. Исходный код хранится в отдельном закрытом репозитории; здесь размещаются готовые ZIP-архивы программы.

## Совместимость

GLORY предназначена для работы с картами OMSI / openOMSI, содержащими стандартную структуру карты с `global.cfg`, файлами `tile_*.map` и данными сплайнов. Результат генерации рекомендуется проверять в openOMSI на резервной копии карты.
